
# Bean There, Modeled That ☕

## Project Overview

Bean There, Modeled That is an end-to-end data analytics and dimensional modeling project based on a multi-store coffee shop business.

The project explores how data can be used to analyze sales performance, product profitability, customer loyalty, inventory management, waste, and workforce operations.

The objective is to build a structured analytical data solution, starting with business requirements and realistic source data generation, followed by dimensional modeling and business-focused analytics.
